# Changelog

- `Unreleased` stays at the top; its contents move into a version section at each release.
- Write the impact for the reader, never copy commit messages.
- Only notable changes. Leave out refactors, renames and small fixes.

```markdown
## [Unreleased]

### Added

- Support for OpenTelemetry tracing.

### Changed

- Improved cache invalidation to reduce stale data.

---

## [1.0.1] - 2026-07-01

### Fixed

- Updated dependencies to address known vulnerabilities.
```
