# Aurore.Foundation.AspNetCore

ASP.NET Core building blocks: JWT and API key authentication, a request pipeline, minimal endpoints with versions, health checks and HTTP dependencies.

## Install

```
dotnet add package Aurore.Foundation.AspNetCore --prerelease
```

Every version is a preview for now, so a version or `--prerelease` is required.

It brings Aurore.Foundation.Core, Aurore.Foundation.Telemetry along.
