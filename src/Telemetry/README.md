# Aurore.Foundation.Telemetry

OpenTelemetry logs, metrics and traces over OTLP, with the personal data of spans encrypted.

## Install

```
dotnet add package Aurore.Foundation.Telemetry --prerelease
```

Every version is a preview for now, so a version or `--prerelease` is required.

It brings Aurore.Foundation.Core along.
