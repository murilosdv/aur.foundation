# Aurore.Foundation.OpenApi

Provider-independent OpenAPI documents for ASP.NET Core: one per API version, document info, security schemes and the documented headers of the foundation. Add the Scalar or the Swagger package for a UI.

## Install

```
dotnet add package Aurore.Foundation.OpenApi --prerelease
```

Every version is a preview for now, so a version or `--prerelease` is required.

It brings Aurore.Foundation.AspNetCore along.
