# Aurore.Foundation.EntityFrameworkCore

Provider-independent Entity Framework Core support: conventions, soft delete, timestamps, paging and unique-violation errors. Add a provider package next to it.

## Install

```
dotnet add package Aurore.Foundation.EntityFrameworkCore --prerelease
```

Every version is a preview for now, so a version or `--prerelease` is required.

It brings Aurore.Foundation.Core along.
