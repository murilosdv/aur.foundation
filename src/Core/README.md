# Aurore.Foundation.Core

Results and errors that map to HTTP, features with decorators, numbered and cursor pagination, entities, privacy of logs and the settings models shared by the Aurore packages.

## Install

```
dotnet add package Aurore.Foundation.Core --prerelease
```

Every version is a preview for now, so a version or `--prerelease` is required.
