# Aurore.Foundation.OpenApi.Scalar

The Scalar reference UI for the OpenAPI documents of the foundation: one document per API version and sign-in with PKCE.

## Install

```
dotnet add package Aurore.Foundation.OpenApi.Scalar --prerelease
```

Every version is a preview for now, so a version or `--prerelease` is required.

It brings Aurore.Foundation.OpenApi along.
