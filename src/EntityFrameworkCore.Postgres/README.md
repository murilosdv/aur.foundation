# Aurore.Foundation.EntityFrameworkCore.Postgres

Entity Framework Core on PostgreSQL for Aurore projects: the Npgsql provider, snake case history table, filtered indexes, unique violations and health check.

## Install

```
dotnet add package Aurore.Foundation.EntityFrameworkCore.Postgres --prerelease
```

Every version is a preview for now, so a version or `--prerelease` is required.

It brings Aurore.Foundation.EntityFrameworkCore along.
